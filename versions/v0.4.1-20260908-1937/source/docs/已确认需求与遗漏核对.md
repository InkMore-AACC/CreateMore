## 1. 产品定位与平台【已确认】

1. Windows 为唯一交付平台。
2. 软件面向本地创作；画布只是整个软件的一层，另有项目、资源管理、连接、设置和诊断页面。
3. 参考 LibTV 画布内的节点、工具、组件和操作；不复刻官网首页、会员购买、积分购买或推广入口。
4. 软件整体界面自主设计，深色、圆角、细描边、浮动工具栏等视觉语言与 LibTV 相对统一。
5. 没有自建中央服务器、没有产品账号注册；局域网协作由成员运行的软件承担服务。
6. 生成来源包括本机 ComfyUI、外部 API 平台（如 RunningHub）、本机 Codex；适用的 LLM 功能还支持本地模型。
7. 本地媒体处理承担截取、音视频拆分等可由代码或媒体程序完成的工作，不强制全部转为 AI 工作流。
8. 不把“完整参考 LibTV”的意图写成“已逐项验证全部功能”。部分底层行为和菜单仍需功能清单核对。

## 2. 六类概念必须区分【已确认】

| 对象 | 定义 | 配置与使用 |
|---|---|---|
| 普通生成节点 | 图片、视频、音频、文本等固定用途卡片 | 可选适用来源；每种普通节点的 ComfyUI 配置绑定一套工作流 |
| 自定义节点 | 软件自带的通用工作流卡片 | 可从设置中添加的多个工作流中选择，端口与布局随映射变化 |
| 卡片工具 | 选中有内容的卡片后，顶部出现的图标与文字组件 | 可以由工作流、模型调用、本地代码或脚本实现；不是节点卡片 |
| Skill | Agent 或功能执行时使用的方法、说明及附属资料 | 有封面、管理页和 `/` 调用入口 |
| 风格卡片 | 将风格 Skill 放入画布形成的卡片 | 一个输出端口；处理生成指令，最终素材由相连生成节点产生 |
| 预设 | 已配置且连接好的一组节点卡片 | 应用时复制到当前画布，不自动生成 |

## 3. 项目、画布与素材【已确认】

### 3.1 文件组织

- 项目文件夹与画布文件可以从任意有权限访问的位置打开，不依赖软件安装目录。
- 一个项目拥有多个画布；每个画布在项目目录下有同名子目录。
- 画布目录按素材类型使用英文子目录，例如 `audio/`、`video/`，并保存图片、文字等内容及自定义工作流。
- 专门的自动保存目录只放画布历史自动保存文件。
- 项目与画布目录中的 `workflows/` 用于项目／画布自定义工作流。
- 精确目录树、工程扩展名、当前画布主文件位置以及名称冲突规则仍需形成文件格式规范，不能用示意目录替代正式决定。

### 3.2 引用、删除与整理

- 画布可以引用项目外的素材，不要求一律复制进项目。
- 删除卡片只删除画布上的卡片；已保存的引用素材副本、生成素材及生成历史继续保留。外部引用的原文件不因此搬入项目或被删除。
- 左侧素材浏览栏默认有“外部素材”和“生成素材”。
- 支持新建、重命名、删除虚拟文件夹，以及移动素材进行分类；这些操作不创建或移动磁盘文件夹。
- 外部文件移动或删除后，支持重新定位；指定一个文件后，尝试按新目录批量找回其他缺失文件。匹配有歧义时不能静默选错。
- 素材库删除素材记录、永久删除文件及历史清理，不能等同于删除卡片；具体操作边界见待细化清单。

### 3.3 打包

- 支持打包整个项目，也支持单个画布。
- 打包到新的独立项目目录，复制内部素材、外部素材和所需画布数据，保持标准项目结构。
- 重写包内引用，使其不再依赖原来的外部素材路径。
- 项目／画布自定义工作流随包保存。
- **不打包本机默认工具工作流，包括用户替换过的版本；不提供“附带本机工具工作流”选项。**
- 密钥、登录凭据不作为项目资源分发。

### 3.4 跨画布复制

- 复制选中的卡片、参数、当前素材、相对位置及选区内部连线。
- 通向未选中卡片的连线不复制，并提示需要补充的输入。
- 粘贴生成独立实例，归当前操作者所有；不改变原卡片。
- 跨项目带入必要素材和自定义配置；本机默认工作流不自动复制。
- 不复制正在执行的任务，不因粘贴自动生成。

## 4. 局域网协作【已确认】

- 画布可随时选择是否共享；共享可选择无密码或有密码，有密码时加入需验证。
- 默认每位成员下载完整素材，作为继续工作的本地基础。
- 发起共享的电脑退出或关机后，允许另一台电脑接管继续编辑。
- 每位成员只能修改自己的内容；可以引用别人的内容，也可以复制后作为自己的内容使用。
- 不因是共享发起者、协调者或资源拥有者而获得修改别人卡片的权限。
- 每位成员的卡片颜色不同，并保持可辨识的成员标记；错误标记独立于成员颜色。
- 成员默认使用自己的 ComfyUI/API/Codex；可主动向成员共享执行资源。
- 共享资源不等于发送密钥或登录凭据给成员。
- Codex 对话每人独立，可主动共享；画布改动实时同步，不自动合并私人对话。
- 普通成员只能暂停、取消、清空自己的任务。
- 资源拥有者可暂停自己设备的整体调度、停止占用自己设备的任务，但仍不能修改别人的卡片。
- 自动整理画布只影响可编辑的本人内容；缩放、小地图和隐藏连线属于个人视图，不改变其他成员视图。
- 接管画布与迁移正在执行的计算任务不是一回事；断线、双主协调与任务恢复需在开发中单独验证。

### 4.1 共享副本与会话生命周期【已确认】

- 首次加入同步画布和完整素材，后续新增素材继续同步；未完成显示同步中。
- 外部引用在原电脑保留原路径，其他成员副本保存到各自画布的对应素材分类目录。用固定素材标识关联，每台电脑分别记录路径；副本是持久素材而非可随意清理的缓存。
- 发起电脑退出／关机允许其他成员接管；主动停止共享结束本次会话并停止同步；单个成员离开不影响其他成员。
- 停止共享不删除或收回成员已有文件。
- 可另存为独立画布，使用新画布身份，保留布局、连接和素材，副本卡片归当前用户；不改变原共享画布权限。
- 同一画布重新开放需验证当前密码并同步缺失内容；独立副本不自动合并回原画布。
- 修改密码后当前成员重新验证，但不能撤回已下载素材。
- 停止共享不等于取消已提交任务；按资源实际可用性处理，明确显示状态并保存可取得结果。

## 5. 生成、队列与结果【已确认】

### 5.1 两个队列

画布左上角任务按钮展开后显示：

| 区域 | 规则 |
|---|---|
| ComfyUI 队列 | 同一个 ComfyUI 实例串行执行，不并发压入同一设备 |
| 外部生成队列 | 按来源限制并发；包含 Codex Image2，并明确标注来源 |

- 展示实际可取得的执行状态、进度和错误，不伪造精确百分比。
- 暂停队列停止后续调度，不声称冻结当前生成。
- 尚未执行的单项任务可暂停；运行中是否可暂停取决于来源能力。
- 取消与暂停分开：运行中取消必须看后台实际反馈，不能只改界面文字。
- 清空／移除不等于取消所有运行中任务，也不删除素材与诊断历史。
- 不支持的操作明确说明，不提供虚假的成功反馈。

### 5.2 稳定性

- 卡片与任务分开管理；取消选择、切换画布不终止已提交任务。
- 提交时固定输入、参数和执行配置；后来编辑不改变该任务。
- 超时或断线后先核对任务状态，不盲目重复提交。
- 结果需要保存并关联到卡片／历史，不能仅凭远端成功提示认定完整成功。
- 软件重启、取消竞态、迟到结果及写盘失败应可追溯。
- 原生 ComfyUI 界面提交的任务标为外部任务；不擅自清空，不误停无法确认归属的任务。

## 6. ComfyUI 接入与映射【已确认】

### 6.1 运行方式

- 首次选择本机 ComfyUI 安装位置与启动配置，此后由画布在后台启动。
- 沿用原 Python 环境、启动参数、模型路径与第三方节点，不另建一套生成环境。
- 启动前检测实例，避免重复进程、端口冲突与显存争抢。
- 提供“打开当前 ComfyUI 界面”，连接画布正在使用的后台。
- 关闭映射界面不结束后台；退出软件时要区分画布启动的进程和用户自行启动的进程。
- 软件不默认更新 ComfyUI、安装第三方节点或改动依赖。

### 6.2 映射编辑

- 参考 DX OS 的布局：嵌入原生 ComfyUI 工作流界面，通过小型连接扩展与映射面板联动。
- 用户可只导入普通工作流 JSON，无需手动提供 API.json；兼容 API 格式导入。
- 工作流节点可选中，右侧设置公开输入、输出、显示名称、说明、默认值、参数范围和布局。
- 素材输入由软件传递给实际执行设备，不能简单传一个只有发起电脑识别的路径。
- 明确指定可取得的输出和主预览，支持多个输出；内部数据并非都能直接保存为素材。
- 同时维护普通工作流 JSON、API 执行数据和映射配置。
- 保存先检查并完成转换，再整体更新当前文件；失败保留上一份可用配置。
- 导入外部工作流默认保存副本，不覆盖用户原始源文件。
- 采用当前原生前端及扩展的转换逻辑，不能仅凭通用字段猜测第三方节点转换方式。
- 正在执行的任务不受保存覆盖影响。

### 6.3 默认工作流的特别规则

- 软件安装目录自带默认工作流，使用者可依据自己的电脑编辑、替换。
- 更新软件可带来默认工作流更新与新增工作流。
- 设置中提示用户自行备份；可通过拷贝回来覆盖恢复。
- **不自动将默认工作流版本快照保存到项目／画布，不随打包带走。**
- 默认工作流规则不等于自定义节点的版本保护规则；二者必须分别实现。

### 6.4 默认工作流的跨设备映射【已确认】

- 卡片的公开输入输出使用固定含义／标识，每台电脑分别映射到自己的工作流节点和参数；不按显示名称相似或文件同名猜测兼容。
- 用户可按硬件替换内部工作流，原有自行备份、不自动复制进项目、不打包默认工作流的规则不变。
- 替换工作流后编辑对应映射，保存时同步更新执行数据与映射。手动恢复备份需恢复配套配置；旧映射失效则提示修复，不继续错误提交。
- 提交前检查素材数量、尺寸、参数范围和输出类型，不静默丢弃不支持的输入。
- 本机执行使用本机映射；共享设备执行使用该设备映射。提交前显示执行设备与可用参数，切换设备重新检查。
- 本机不可用不自动切换其他设备或付费 API。设备执行权限不赋予修改他人卡片的权限。
- 兼容检查只保证输入输出契合，不保证不同模型生成同样效果。

### 6.5 兼容验证

- 原生 ComfyUI 跑通不等于画布的映射、提交和结果回传已经跑通。
- 对需要运行中选图、编辑遮罩或文字的节点，不能假装后台自动兼容。
- 检查层次为：文件和映射检查、环境检查、真实生成和结果回传。
- “已验证”标记针对当前工作流和环境；不能宣称所有第三方节点无 Bug。

## 7. Codex、LLM 与 Skill【已确认】

### 7.1 Codex 和模型来源

- 画布内 Agent 优先接入本机 Codex CLI/App Server，使用订阅登录，不要求 OpenAI API 密钥。
- 软件提供 MCP 与 CLI，使桌面端 Codex 也能操作画布；与内置 Agent 共用同一画布操作服务、权限、队列及日志。
- 图片生成最终选择 **Codex 内置 Image2**；它属于可能消耗 Codex 工作额度的来源，不是普通 Chat 额度通道。
- 反推提示词、扩写、剧本转分镜等也可选择 Codex、本地 LLM 或外部 API。
- 按能力筛选来源；纯文字模型不能被当成看图模型，没有视频生成能力的来源不能当成视频生成服务。
- 简单功能与持续 Agent 对话隔离，避免上下文串用；停止聊天不隐式取消已提交生图任务。
- 本机接入、图片参考输入、结果回传、登录复用与恢复能力均仍需实际验证。

### 7.2 Skill

- 软件有独立 Skill 管理页面，支持封面、名称、说明、分类、启停、导入与编辑；Agent 输入 `/` 调用。
- 软件 Skill 与本机 Codex Skill 统一呈现，但不直接合并覆盖原文件。
- 可选择引用本机 Skill，或复制为独立个人 Skill；需检查依赖与运行能力。
- 引用的原文件默认不通过画布管理页直接修改。
- 软件内置、个人、项目／画布及引用的本机 Skill 标明来源。
- Skill 通过统一工具执行，不绕过成员权限；提示词说明不等于任意代码执行授权。
- 记录调用版本、输入与结果；管理界面禁用需真实影响加载，不能只是隐藏菜单。

## 8. 普通生成节点【已确认】

- 创作资源下设独立“普通生成节点”配置入口，分图片、视频、音频、文本。
- 每类配置 ComfyUI 的一套绑定工作流及映射、可用 API 平台／模型、适用的 Codex／本地 LLM 和默认参数。
- “连接”管理安装位置、地址、密钥与登录；“普通生成节点”管理使用这些连接的方式。
- 卡片内选择本次来源和参数，并提供直达对应配置的设置入口。
- 明确公共配置与当前卡片参数的作用范围。

## 9. 卡片顶部工具【已确认】

- 由图标和功能文字组成；只有卡片被选中且有内容时显示。
- 可以由 ComfyUI、API、Codex／LLM、本地代码或脚本实现。
- 独立“卡片工具”设置页，按文本、图片、音频、视频分类，支持添加自定义工具、命名、图标、排序、启停、工作流及映射配置。
- 软件自带和用户自定义工具均放在软件安装目录的相应位置；内置与自定义分开管理，更新保留自定义工具。
- 工具过多放入“更多”；缺素材或缺配置显示具体不可用原因。
- 处理结果默认创建新的结果卡片并关联来源；预览、复制、下载不必新建卡片。
- 只有明确选择“应用到当前卡片”时更新自己的卡片，保留旧素材和历史。
- 多结果操作可生成多张卡片。
- 多选只显示支持批量的工具。
- 使用别人的素材处理时创建自己的结果，不修改别人的内容。

## 10. 自定义节点【已确认】

- 软件自带一种通用自定义节点，设置中可绑定多个工作流，添加、编辑映射和删除绑定。
- 卡片选择工作流后，其输入输出端口、参数控件和布局随该映射改变。
- 各卡片实例分别保存所选工作流、参数、素材及历史，互不影响。
- 允许多种输入输出及可扩展的数据类型；特殊模型对象等不自动视为可持久化、跨设备的普通素材。
- 顶部工具栏跟随当前预览／选中的输出素材；无对应类型则不显示。
- 切换保留旧配置并可撤销；只沿用明确兼容的连接，不兼容处提示解除或重新配置。
- 旧任务继续按原输入执行；迟到结果进入相应历史，不错误写入新工作流端口。
- 设置更新供新建实例使用，已有实例主动应用更新。
- 删除绑定从选择列表移除，不破坏已有卡片；已有卡片保留必要自定义配置。
- 软件安装目录中的自定义工作流库是统一源头，保存普通工作流、执行数据和映射配置。
- 画布首次选择某个工作流时，将所需配置复制到当前画布的 `workflows/`；同一画布相同版本只保存一次，各卡片参数、素材、连线和历史独立。
- 在软件库编辑产生新版本，已有卡片不自动更新；“编辑本画布映射”保存为画布内新版本，默认仅当前卡片切换。其他卡片可主动更新，更新前检查连线影响。
- 删除软件库条目不影响画布副本；删除卡片不立即删除工作流，以保护历史恢复。
- 跨画布复制带入所需配置，相同版本复用；打包包含画布自定义工作流。模型和第三方节点不随工作流自动带走。
- 可将画布内修改后的版本保存回软件工作流库。
- 第一版不增加项目级共享工作流的独立编辑／跟随更新规则，每个画布自带完整自定义配置。
- 以上不适用于软件默认工作流：默认工作流仍不自动复制到画布、不随项目打包。

## 11. 预设、角色与风格【已确认】

### 11.1 预设库

- 预设是一组已经连好且填好参数的卡片，例如角色参考图连接人物设定图生成节点。
- 任意画布框选节点，右键添加为预设并填写名称。封面可从选区图片选择、自行上传，或自动生成节点组缩略图（不调用 AI）；默认有图片用图片，无图片用节点组缩略图，之后可更换。
- 保存节点、内部连线、配置和必要参考素材。
- 应用到当前画布创建独立副本，归当前成员，不自动生成；替换参考素材后可以使用。
- 修改副本不影响库里的原预设或其他副本。
- 预设缺少模型、工作流、连接或 Skill 能力仍允许添加，保留节点、连线与参数，在受影响卡片上标明原因；无关节点可继续使用，不自动执行。
- 问题卡片提供相关配置、素材重新指定或可用来源选择入口；修复后重新检查，不要求反复填写已通过配置。
- 无法识别的节点显示占位卡片并保留原始配置、位置和连接，不丢弃；不静默替换模型、安装第三方节点或切换付费来源。

### 11.2 角色库

- 角色是用户主动建立的可复用资料集合，不限人物，动物、物品或石头均可；普通素材导入画布绝不自动创建角色。
- 用户选中素材后选择“创建角色”，或在角色库新建。名称与封面必填；封面从图片指定或另行上传。
- 故事、性格、背景等文本、设定图、声音样本、视频及其他附件均可选，不要求固定资料组合；支持标签、筛选与最近使用。
- 创建时复制选定资料进角色文件夹，原素材不变。应用到画布选择需要的资料创建相应卡片，不重复创建角色；画布修改不自动覆盖库，更新需明确操作。
- 应用到画布导入选中资料，不自动提交生成。
- 不将 LibTV 官方角色资产默认视为软件可分发的自带素材。

### 11.3 风格库

- **没有特效库。**风格库展示适用的风格 Skill，与 Agent Skill 共用。
- 添加风格 Skill 到画布创建风格卡片，只有一个输出端口，可对接适用的图片、视频、音频、文本生成卡片。
- 根据目标节点的参考素材、原提示词和其他明确输入，处理得到风格化生成指令。
- 最终素材由目标生成节点生成，风格卡片不直接生成最终图片／视频。
- 保留原提示词，处理后的指令可查看、复制和追溯。
- 一个风格卡片连接多个目标时分别处理，不混合上下文。
- 修改后标记需更新，不自动生成；执行时固定输入。
- 读取目标原始输入再输出指令需要避免形成执行环，见技术验证清单。
- 一个目标可连接多个风格卡片；目标内显示列表，默认按连接顺序，可拖动排序或临时禁用。
- 按顺序处理：原需求与参考素材经过各 Skill，后一步读取前一步结果并保留原始需求与素材，最终指令交给生成节点；不简单拼接多份结果。不同目标分别执行和记录。
- 风格处理失败阻止后续素材生成，提供重试失败步骤、本次跳过该风格、取消；不自动跳过、不使用过期结果。输入、顺序或 Skill 改变后从受影响步骤重新处理。
- 默认点击生成连续执行风格处理和素材生成；另提供仅预览生成指令，可查看原文、各步骤与最终指令，不提交最终素材生成任务。

### 11.4 资源保存、分享与打包

- 软件安装目录下分别使用 `presets/`、`characters/`、`skills/`；每个预设、角色、软件管理的 Skill 都有以自身名称命名的独立文件夹，配置、封面及附属文件集中其中。
- 软件内置与用户自建资源分开管理，更新保留用户自建资源。重命名同步文件夹；同名或非法 Windows 名称提示处理，不静默覆盖。
- 引用本机 Codex Skill 保持原位置，不擅自移动或覆盖。风格库是共用 Skill 的分类，不另维护重复源文件。
- 保存预设收集节点、内部连线、参数、必要素材与自定义配置，不保存运行任务，也不默认收集全部生成历史。
- 应用资源后画布保存必要的独立内容；风格卡片保存所用 Skill 版本及资料，库更新需主动应用，删除库条目不破坏旧画布。
- 支持分别导出预设、角色或 Skill 供其他人导入；同名默认新增并区分，不直接覆盖。
- 打包画布／项目仅带已使用并保存的资源，不复制整个个人库；默认工作流仍不带入，记录依赖并检查。模型、第三方节点、密钥和登录凭据不随资源包带走。

## 12. 界面、导航与画布底部【已确认】

### 12.1 整体结构

- 项目首页＋画布工作区＋独立管理页面。
- 主导航：项目、局域网、创作资源、连接、设置。
- 创作资源含：普通生成节点、卡片工具、自定义节点、Skill；预设／角色／风格的全局管理归属尚需细化。
- 项目首页支持新建、打开、最近项目；项目内展示多个画布与实际路径。
- 深色视觉，青蓝用于主交互；成员颜色不大面积遮盖素材。
- 管理页切换后保留画布视野、选区、输入和任务；复杂配置明确保存／取消，日常画布自动保存。

### 12.2 画布布局

- 卡片未选中无常驻外描边；选中后用很窄的描边表示选区，草图采用 2 像素。
- 图片生成节点未选中时呈简洁灰色卡片，不常驻展示来源、参数与生成按钮；选中时再弹出编辑区域。已有结果的最终展示细节继续按素材卡片设计核对。
- 生成任务弹窗中本地 ComfyUI 与外部生成采用左右两列，不上下堆叠。
- 普通浮动窗口支持点击画布空白处关闭，同时保留关闭按钮；需要保存的编辑内容继续遵守保存／取消规则，不静默丢弃修改。
- 卡片不使用常驻灰色外边框，减少外壳和留白，让内容获得更多空间；选中和成员身份通过轻量标记表达。交互及卡片功能排版继续参考 LibTV。
- 左上：项目返回、名称、画布切换、生成队列入口。
- 顶部右侧：保存状态、共享与成员、更多操作。
- 左侧：可收起的素材浏览与生成历史。
- 中央：无限画布。
- 右侧：可收起的 Agent；支持 Skill 封面与 `/` 调用。
- 卡片上方：选中且有内容时显示适用工具。
- 当前画布可以直接打开诊断面板。

### 12.4 基础交互【已确认】

- 双击空白、右键菜单或 Tab 打开节点创建菜单；单击选中、框选多个、Shift 增减选区，空格拖动画布，文字编辑时不触发画布快捷键。
- 他人卡片可选中、查看、引用和复制，不可移动或修改。
- 自己的卡片可成组、命名、折叠、整体移动；解组保留卡片位置和连线，分组不生成、不改变素材归属。
- Ctrl+C/V 复制粘贴，Ctrl+D 在旁边复制选区，Alt+拖动创建独立副本；保留内部连接，不复制运行任务、不自动生成。
- 输出连接兼容输入，不兼容明确原因；单值输入提示替换，多值输入支持排序；删除连线不删除素材与卡片。
- 普通自动执行依赖不能形成相互等待的环；这不等于禁止使用已完成的历史素材再次生成。风格处理按已确认的特殊流程组织，不把读取目标原始输入当成等待目标最终输出。

### 12.5 特殊创作功能范围

- **3D 导演台：暂不实施，仅预留位置。**用户描述的后续目标包括简易 3D 预览、OBJ 与动画序列帧导入、钢笔编辑多机位摄像机路径及关键帧、近似 3ds Max 的视图操作；图像生成角色／物品／场景模型依赖工作流或 API，最终输出剪辑好的摄像机动画供视频生成参考。这些不是当前开发验收要求。
- **逐帧拉片：已确认需求。**从视频卡片顶部工具进入，选择整个视频或指定时间范围、适用的多模态模型或 ComfyUI 工作流，可补充分析重点。软件组织取帧与分析，不要求手动逐张截图，也不把名称理解为逐帧调用模型。
- 拉片结果为可编辑分镜表格，默认一行一个镜头，包含镜头编号、时间范围与时长、代表截图、分镜描述、分镜提示词。描述涵盖主体、场景、动作、景别、构图及镜头运动；截图可补充起始、结束或中间帧。
- 点击截图或时间定位原视频；截图时间来自实际取帧记录，不由模型编造。镜头划分可调整、拆分、合并。
- 默认在画布创建一个关联原视频的结果卡片，展开编辑完整表格，不自动铺开大量节点。可选择行复制描述／提示词、将截图与文字添加到画布，或导出附带截图的 Excel；这些操作不自动生成媒体。
- 重新分析生成新版本，不覆盖人工修改；部分失败保留已完成内容并标明缺失范围，不标记整段成功。
- **片段重拍：已确认需求。**在视频时间线选择截图位置，对截图标注修改内容，以参考图和包含对应时间戳的修改提示词，通过工作流生成新视频。输出独立结果卡片并保留原视频，不自动替换或拼回原视频；不将自动回拼作为当前实施要求。

## 13. 日志、诊断与错误定位【已确认】

- 卡片显示易懂错误，点击详情在当前画布展开诊断；不必先进入设置。
- 当前面板按任务筛选，显示步骤、相关输入／配置、原始错误与对应节点。
- 支持选择复制、复制摘要、复制本次日志、导出日志和诊断包。
- 导出和复制过滤密钥等敏感信息。
- 支持定位画布节点，并进一步定位 ComfyUI 映射节点。
- 全局诊断页处理跨画布历史、启动、连接等问题。
- 保存失败或无对应节点的画布错误在顶部持续提示，不能显示虚假的已保存状态。
- 日志、生成历史、画布自动保存分开：原因、产物、恢复版本分别管理。
- 普通运行日志默认保留 30 天，每台电脑总容量上限 1 GB，先清理最旧日志。生成历史不随日志轮换删除，任务关键错误另行保留；详细日志到期需明确标注已清理。私人内容是否附带诊断包仍需明确。

### 13.1 保存、恢复与清理【已确认】

- 自动保存设置提供两个选项：每隔多少分钟保存一次、最多保留多少份。默认 5 分钟、100 份；5 分钟不是另一套固定计时，实际间隔完全由该设置决定。每到设定间隔，仅在画布有未归档变化时保留一份，无变化不重复保存；超限轮换最旧自动保存。
- 明确取消操作结束约 2 秒保存、持续操作最长每 10 秒保存的方案，不另设隐含的操作触发自动保存。
- `Ctrl+S` 立即手动保存。自动保存历史保存结构、参数与素材引用，不反复复制媒体文件。
- 历史恢复先预览，恢复前保留当前状态；不重新提交生成、不删除后生成素材。共享画布提供恢复为独立新画布，遵守他人内容权限。
- 存储管理区分可重建缓存、素材、自动保存与日志。缓存可按容量清理，素材不自动删除，外部原文件不由画布清理删除。
- 主动清理素材前列出大小以及卡片、生成历史、恢复版本的引用影响；当前画布无卡片引用不等于可删除。一键清缓存不包含永久素材删除。

## 17. 内部架构与开发顺序【已确认】

### 17.1 内部模块不等于界面导航

- 整体采用一个 Windows 桌面软件、本机后台服务和可替换的生成连接模块；第一版不拆成许多独立服务。
- 以下五部分是程序内部职责，不是五个新的页面，不替代第 12 节已确认的项目、局域网、创作资源、连接、设置导航及画布布局。

| 内部部分 | 职责 |
|---|---|
| 桌面界面 | 项目首页、画布、卡片、Agent、资源库与设置 |
| 项目与素材管理 | 文件保存、定时自动保存、素材引用、打包与历史 |
| 任务与执行 | 队列、进度、取消、结果保存与错误追溯 |
| 生成连接模块 | ComfyUI、Codex、外部 API、本地 LLM |
| 局域网协作 | 身份、同步、权限、素材传输与接管 |

- 鼠标操作、内置 Agent、外部 MCP／CLI 共用画布操作能力；保存、同步和权限规则一致。
- 卡片与任务分离，素材与卡片分离；界面通过后台执行生成和文件操作。
- 普通节点、自定义节点及卡片工具复用基础能力，不各自建立独立保存或执行逻辑。
- 已选 Electron 44.2.0、Node 本机服务、目录型 JSON 工程与原子保存；局域网使用 Node 标准库加密连接与保守多数确认，详见实施和 LAN 记录。

### 17.2 四阶段推进

| 阶段 | 内容 | 验收重点 |
|---|---|---|
| 一：基础画布与连接验证 | 项目打开保存、卡片连线；分别验证 ComfyUI、Codex Agent、Codex Image2 | 可重新打开工程；真实生成结果落盘并回到正确卡片 |
| 二：个人创作闭环 | 普通／自定义节点、映射、工具、队列、日志、素材与打包 | 单人完整创作、排错及项目迁移 |
| 三：复用与智能功能 | Skill、风格、预设、角色、逐帧拉片与片段重拍 | 资源复用与输入输出追溯 |
| 四：协作与交付 | LAN 同步权限、全量素材、接管、性能、Windows 安装更新 | 多机协作、断线恢复及交付 |

- 身份、内容归属和同步所需的数据结构从第一阶段纳入，不能等第四阶段才改造单人数据模型。
- 第一阶段提供可实际操作的桌面版本供用户调整，不等全部功能完成才评审。
- 界面细节允许迭代；已有项目使用后的文件格式和权限变更需兼容与迁移。
- 3D 导演台仅预留位置，不纳入当前实现范围。
- 本次确认是架构与顺序确认，不等于开始编码；实际实现与验证状态仍按第 16 节记录。
