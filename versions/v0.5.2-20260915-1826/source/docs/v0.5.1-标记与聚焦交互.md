# v0.5.1 标记与聚焦交互

## 本版已实现

- 生成图片卡片的“标记”不再打开旧涂画框。点击后仅当前卡片保持高亮，鼠标变为图钉，直接点击图片物体发起识别。
- 识别结果在图片上显示图钉、物体名称和大致范围虚线框；提示词保存稳定的 `createmore-mark` 链接，执行前转换为物体名称与归一化区域描述。
- 标记识别可在全软件设置中选择本机 Codex、外部 API 或本地 ComfyUI；本地默认使用 Qwen3-VL 看图工作流，与图片生成工作流隔离。
- 标记后的当前图片会作为图片编辑参考参与生成，并据此选择单图／多图本地路由；不支持的参考数量明确报错，不静默丢图。
- 聚焦裁切弹窗的图片按自身比例最大化并贴合图片区域边缘。新卡片固定使用框选得到的自定义比例。
- 1K、2K、3K、4K 自动换算宽、高和像素量，按 8 像素对齐；聚焦结果保证至少 1M 像素，并将真实宽高传给本地裁切与放大工作流。
- 生成卡片设置增加全软件默认来源和外部 API 连接层级；面板增加返回按钮，返回与关闭分离。
- 提示词 `@` 菜单只列已连接图片，顺序与图片输入顺序一致。图片参考选择期间不会误拖动卡片。
- 导入素材、资产取用、历史结果、角色媒体资料和工具结果统一创建普通素材卡片。普通卡片没有下方生成框。
- 图片与视频卡片读取真实媒体宽高并自适应比例，保持完整内容。

## 验证边界

- 代码语法检查及 360 项自动化测试通过，其中新增图钉识别、稳定提示词链接、自身图片参考路由、自定义比例换算、1M 像素下限、图片 `@` 过滤和聚焦界面测试。
- 自动化测试证明状态、路由和交互结构正确，不等于三种识别来源的真实识别质量都已验收。
- LibTV 浏览器控制连接本轮连续失败，未把连接故障描述为网页故障，也未声称完成新的在线观察。
- 按用户最新要求，本版不扩改第 5 项广泛工具工作流与其真实效果；该部分继续单列处理。
