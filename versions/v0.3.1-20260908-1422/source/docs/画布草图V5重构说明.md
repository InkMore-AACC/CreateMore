# 画布草图 V5：整体重建

用户要求：设计、交互、排版高度参考 LibTV，同时满足已确认的 CreateMore 需求。V5 从页面结构、样式和状态逻辑重建，没有继续在 V4 上叠加事件处理。旧版归档在 prototype/archive/main-canvas-v4.html。

## 设计依据

本轮重新读取 Edge 中用户指定的 LibTV 画布，并查看完整截图。依据当前实页及前三轮记录：

- 画布占满主工作区；侧栏为紧凑目录，右侧 Agent 固定输入框、上方保留创作空间。
- 不使用贯穿页面的顶部大栏，画布操作位于悬浮控制条。
- 名称与规格在内容卡片外；未选中不显示外描边；选中显示 2 像素青蓝描边。
- 素材工具位于选中节点上方，参数贴在节点下方。端口在悬停或选中时显示。
- 细灰连接线、相关连接高亮、半透明分组容器、普通浮窗点击空白关闭。
- 图标改为一致的线性 SVG；收紧字号、行高、间距及侧栏密度。

示例画面采用项目内原创 SVG 构图占位，明确标记“构图示意”，没有下载 LibTV 的创作图片，也没有生成视频。

## 已落地的本地交互

| 路径 | 当前草图行为 |
|---|---|
| 创建 | 双击、右键、Tab、目录加号打开菜单；新增独立节点 |
| 选择 | 单选、Shift 增减、框选；目录定位与 Agent 引用同步 |
| 平移缩放 | 空格拖动、中键平移、鼠标位置缩放、适应全部或选区、小地图定位 |
| 移动 | 卡片拖动、多选移动、分组移动，连接线跟随 |
| 连线 | 输出端快捷创建、拖线到输入端、输入端选择参考；拒绝重复、不兼容和循环连接 |
| 复制 | Ctrl+C/V、Ctrl+D、Alt 拖动；复制选区内部连接，剔除对外连接和任务错误状态 |
| 分组 | 创建、重命名、折叠、展开、解组；解组保留卡片和连线 |
| 删除 | 删除卡片或连线可撤销；独立素材记录保留，可再次添加 |
| 撤销 | 创建、连接、复制、移动、分组、删除及文字编辑可撤销和重做 |
| 分镜 | 结构化表格、增行、就地编辑、CSV 导出，回到画布后内容同步 |
| 保存 | Ctrl+S 或顶部保存按钮写入浏览器草稿；默认 5 分钟，有修改才保存；保存失败可见 |
| 文件 | 小于等于 8 MB 的图片、音频或视频可作为测试素材导入；JSON 草图导出 |

## CreateMore 的特别要求

- 使用 CreateMore 自有标识，不引入会员、积分商城等商业入口。
- 左上任务面板始终为 ComfyUI / 外部生成左右两列，未提交任务时显示为空。
- 底部保留预设、风格、角色、帮助、快捷键；不放底部加号、指针和时钟。
- 普通节点、卡片工具、自定义节点、Skill 分开配置；默认来源按类型筛选。
- 视频不提供 Codex Image2，文本和脚本可以选择 Codex 或本地模型；未连接时保留输入并引导设置，不伪造提交或生成成功。
- 3D 导演台禁用并标记预留。分组只有普通分组语义，没有额外“转分镜组”操作。
- 项目、局域网、创作资源、连接、设置入口完整呈现；复杂配置需要明确保存或取消。
- 素材和画布卡片独立。模型层检查卡片归属，不因可以引用而允许修改他人内容。

## 验证及边界

- 两个脚本均通过语法检查。
- 模型层与 DOM 事件测试覆盖创建、复制、连接、删除、素材保留、撤销、持久化、重命名、分镜编辑、队列布局、拖动、缩放、配置保存取消等路径。
- DOM 测试采用内存文档，不是浏览器渲染或截图验证。浏览器此前拒绝自动访问本地文件，本轮未绕过该限制；最终视觉比例和鼠标实操仍需在用户已打开页面中核对。
- 生成、Codex、ComfyUI 原生映射、外部 API、LAN、真实项目文件、媒体处理、正式工程历史快照仍是接入前的界面设计，未声称完成。
- 浏览器草稿与正式项目文件不是同一机制；JSON 导出也不是正式打包。图片多结果计数和音频波形属于明示样例。

本次只重构项目内草图，没有修改全局设置、长期记忆或 LibTV 节点。
