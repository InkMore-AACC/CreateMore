内部结构为一个桌面软件、本机服务和可替换生成连接模块。界面、CLI 和 MCP 复用同一业务服务；文件写盘采用原子替换与备份，不把素材随卡片删除。生产身份、连接、任务、私人对话保存在本机应用数据目录。

没有修改用户 Codex 全局配置、ComfyUI 安装或模型，也没有修改 `prototype/`、`chat-image-probe/` 和嵌套 Git 仓库。仅为本软件保存了本机现有 ComfyUI 环境路径和连接。

## 仍需要环境或用户决定的事项

- **发行**：没有 Windows 签名证书、发布地址或更新服务器，交付本地可运行目录，不自行购买证书或上传发布。
- **真实多机验收**：当前有同机加密网络及真实模型回传证据，没有多台实体电脑、路由器、Wi-Fi 中断、睡眠／唤醒、关机与防火墙测试；不自动改系统网络设置。
- **两机接管选择**：两位成员一位突然离线时无法形成多数；保留独立完整副本，不强制制造双主。若需要无条件两机接管，须另定见证成员或独立分支的产品策略。
- **付费 API**：通用连接及能力入口不等于具体平台验收。RunningHub／其他端点、密钥、所选模型、价格与取消／恢复能力，待提供实际配置后逐一验证，不自动切换收费来源。
- **专用本地模型**：H3 环境音不是准确配音或声音克隆；当前环境缺专用配音依赖。精确遮罩、强身份锁定、严格九宫格等应选专用流程或 Image2，不能把通用图生图结果包装成能力保证。没有自行下载大模型或改变环境。
- **规模及兼容性**：已有 1,000 节点／750 媒体资源的受控界面压力测量，不等于多电脑长时间生产压力验收。12 套工作流兼容不代表任意第三方 ComfyUI 节点都已验证。
- **3D 导演台**：按已确认要求仅预留，未列作当前生成能力。
