# CreateMore 使用说明

## 第一次打开

打开交付目录的 `CreateMore.exe`。在项目页新建工程，或者选择带 `.createmore.json` 的项目文件夹。工程可以放在任意有权限的位置，不依赖软件安装目录。不要把工程建在软件的临时测试目录内。

项目根目录 `examples/实机验收工程` 已包含真实素材，可直接打开。保留原始验收副本，建议先通过项目页“打包”另存一份练习工程。

## 画布基本操作

- 双击空白处、右键或 Tab：添加节点。
- 单击选择、Shift 增减选择、空白拖动框选；空格拖动平移，滚轮缩放。
- 从输出端口拖到输入端口连接。自定义节点按映射显示具名端口，错误类型会拒绝连接。
- Ctrl+C/V 跨画布复制，Ctrl+D 就近复制；副本不复制运行任务、不自动生成。
- Ctrl+Z 撤销自己的编辑；输入框内快捷键优先编辑文字。
- 多选后可分组、命名、折叠和移动；不会把普通分组当成一种生成任务。
- 底部可整理本人的内容、开小地图、隐藏连线、切换网格吸附和缩放。

## 图片、视频、文字与音频

选中节点后设置来源与提示词，点击箭头提交。来源按实际媒体能力区分：

| 用途 | 已接通来源 | 注意 |
|---|---|---|
| 图片 | 本地 Z-Image、Codex Image2 | 图片可逐份生成 1–8 份；参数支持以所选来源为准 |
| 视频 | 本地 H3、用户配置的外部工作流 | 图片首帧参考使用对应 I2V 工作流，不自动回拼原视频 |
| 文字 | 本机 Codex、本地 Qwen、兼容 LLM API | 本地模型的视觉能力必须真实支持，不能仅有名称 |
| 音频 | 本地 H3 环境音工作流 | 不冒充精确台词配音或音色克隆 |

普通节点的默认工作流在“创作资源 → 普通生成节点”配置。尺寸、步数、种子等映射参数按具体工作流显示；Image2 的提示要求不等于来源保证精确尺寸或种子。

卡片上方工具作用于当前真实素材。放大、裁切、尺寸、音量可用对应本地流程；截取、变速、切分、取帧、抽音轨使用本机 FFmpeg，不消耗生成额度。工具结果另建卡片并保留原素材。

任务面板分为本地 ComfyUI 和其他来源两列。同一实例串行，其他来源按上限并发。取消必须有来源确认；“需核对”不等于失败，也不应马上重复提交。核对原任务不会盲目再生成。已知失败的多份生成或拉片可只重试未完成部分。

## ComfyUI 与自定义工作流

在“连接”检查现有安装路径、原 Python、地址和启动参数。软件只管理自己启动的后台，不关闭用户另开软件启动的实例；退出 CreateMore 默认保留 ComfyUI 后台。没有任务时可在连接页停止本软件拥有的实例。

自定义工作流可以导入普通 GUI JSON；软件打开独立的原生 ComfyUI 编辑窗口，通过当前前端转换 API 数据。修改后同步回来，在映射中定义固定输入 ID、类型、范围、参考图及输出。校验失败保留上一个可用版本。关闭原生窗口只隐藏它，未同步草稿继续保留；不影响你其他浏览器的工作流。

默认工作流属于本机资源，**不会随项目打包**。自定义节点使用独立版本，保存到资源库和更新已有卡片是不同操作；正在执行的任务继续使用提交时的版本。

## 资源、风格与角色

预设、角色、Skill 和工具各有独立资源目录，可搜索、按标签筛选；最近使用只统计本人在当前画布成功使用的记录。

预设保存选区中的节点和内部连线；封面可用选区图片或本机图片。应用只创建独立副本，不生成。角色资源可以选择需要的描述、文字资料和素材，不强制一次全部加入。

Skill 可以编辑、复制、停用和导入；外部 Skill 默认只读引用。修改内置条目时保存个人副本，不覆盖内置源。`/` 菜单和方法卡只加载真实启用的方法。

风格卡处理生成指令，不直接输出最终素材。多个风格按目标设置顺序处理，保留原始指令与每步结果；一个步骤失败时停止后面的素材生成。已成功步骤可复用，未知步骤先核对，不重复提交。

## 私人 Agent

内置 Agent 使用本机 Codex 订阅登录。`@` 引用节点，`/` 选择 Skill，Agent 可以读取画布、创建和修改自己的卡片、按具名端口连线、提交独立任务并查看真实状态。

私人对话不自动共享。需要共享时点击“主动分享到画布”，确认后复制为自己的文本卡。停止私人对话不会取消已经提交的独立图片任务。断线回合通过“核对原回合”恢复；缺少远端编号时保留未知状态，不假称已经取消或重发成功。

聊天历史保存在本机，记录原工程、画布、所选 Skill 的版本和内容指纹。继续历史对话前留意当前作用画布。外部 MCP/CLI 与内置 Agent 使用同一权限校验，不具有修改他人卡片的额外权力。

## 逐帧拉片与片段重拍

从视频卡片工具进入“逐帧拉片”，选范围、取样间隔和具备视觉能力的来源。它按真实时间提取代表帧再分析，**不是已保证自动识别每一个剪辑切点**。本地模式已接 Qwen3-VL，默认代表帧间隔可以调整。

输出为一个可编辑分镜表。可修改描述和提示词、拆分或合并行、定位原视频、取用文字和截图，或导出带截图的 Excel。重新分析另建版本，不覆盖人工修改。断线时已完成批次保存在本地；“查看已完成范围”可先取回部分版本，未知批次仍需核对。

“片段重拍”先定位原视频时间，再在截图上用画笔、矩形、箭头或编号标注。生成新片段时使用该参考图和时间戳，不改原视频，不自动替换或拼回去。

## 素材、保存、恢复和迁移

外部素材可引用或复制。文件移动后重新定位会核对内容，拒绝把不同内容冒用为旧素材。虚拟文件夹只整理分类，不移动磁盘文件。删除卡片不删除素材、生成历史或外部原文件。

Ctrl+S 立即保存；定时保存的分钟与最多份数在设置中统一控制。退出前会同步最后一笔输入，保存失败则保留窗口。恢复历史先预览并保留当前状态；共享内容使用独立副本恢复，不覆盖别人的编辑。

项目/单画布“打包”复制所需内部、外部素材及自定义工作流，改写相对路径，形成独立工程。机器凭据、私人聊天、本机默认工作流不进入包内。接收者副本可独立编辑，不改变原共享画布。

存储管理只自动整理可重建缓存和按规则轮换日志；真实素材不自动删除。手动清理成功风格缓存会移入本机缓存回收区，重新生成可能消耗额度。

## 局域网协作

只有主动共享/加入后才监听局域网。可设置密码，成员应核对主机指纹。成员只改自己的内容，可引用或复制他人的内容；完整素材以分块和哈希校验保存到本机。私人视野、凭据和对话不自动同步。

执行设备必须由设备主人主动开放。可开放已配置的 ComfyUI 工作流、Codex 文字、Image2、Ollama、兼容文字 API，以及有固定云端编号和本机映射的 RunningHub 工作流。选择设备后只设置其公开参数，凭据、后台路径、私人 Agent 对话和工具不发给成员。

Codex／Image2／付费 API 必须由主人单独勾选允许成员使用本设备账号额度或费用，默认不勾选。可限定成员，不提供自动费用上限或分账。资源主人按来源暂停后续调度、控制自己的设备任务，不因此获得他人卡片编辑权。配置或账号变化后需重新开放；重启不会自动重新开放。同步文字 API 未必能确认远端取消或停止计费，未知状态不会自动重发。失败或取消前已完成的真实结果会先校验并保留。

尚未通过真正的多电脑测试。当前接管需要多数成员确认：三位成员两位在线可以接管；两位成员失去一位时不能安全强制接管，可另存独立工程继续。不要将同机网络测试当成所有路由器、睡眠和断电场景都已可靠。

## 遇到问题

先打开当前画布的“诊断”。记录任务、来源、时间和错误摘要；可定位卡片、复制脱敏日志或导出诊断包。不要反复点击生成来尝试消除未知状态。

外部 API 需要自己的准确端点、模型/工作流和密钥；未配置时不会自动改用它。Windows 签名、发布与自动更新尚未配置，本地版不自行购买或上传工程。
