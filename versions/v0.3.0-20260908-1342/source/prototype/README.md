# CreateMore 全新画布草图 V5

直接打开 main-canvas.html。页面结构、视觉样式、画布数据与事件逻辑均已重建；旧版保存在 archive/main-canvas-v4.html。

## 先体验这些操作

1. 滚轮缩放，空格拖动或中键平移；从左侧目录定位不同节点。
2. 选中图片，看上方工具条和下方附着参数区；点击空白收起。
3. 双击空白新建节点；点击输出加号创建下游，或拖动输出到另一节点输入端。
4. 拖动空白框选，Shift 增减选区，Ctrl+D 复制，Ctrl+G 分组，Ctrl+Z 撤销。
5. 打开分镜脚本，改写单元格、添加镜头、导出 CSV。
6. 打开左上任务面板和底部预设、风格、角色库；通过品牌菜单查看五个管理入口。
7. Ctrl+S 保存浏览器草稿，默认 5 分钟有修改才自动保存；重开同一浏览器可恢复。项目面板也能导出 JSON。
