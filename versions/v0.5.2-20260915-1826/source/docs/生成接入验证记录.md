## 接入契约

`ProviderHub({appDir,dataDir,encryptSecret?,decryptSecret?})` 提供 `ready`、`status()`、`configure(patch)`、`prepare(snapshot)`、`run(snapshot,options)`、`reconcile(snapshot,remote,options)`、`cancel(remote)`、`stopComfyOwned({url?,instanceId?})`、`close()`。

提交队列前应 `await hub.prepare(snapshot)`。它冻结来源地址、选择模型、参数连接与机器凭据引用；不把明文 key 放进项目任务。凭据通过 Electron safeStorage 回调保存在独立机器加密库，旧任务可在更换当前 key 后继续查询。没有加密能力时密钥只存内存，重启后旧任务凭据不可恢复时明确报错，不能偷换当前 key。

来源：`comfyui`、`codex`、`image2`、`ollama`、`openai-compatible`、`runninghub`。

- `snapshot`：`provider, kind, prompt, references:[{path,type}], workflow:{gui,api,mapping}, parameters, model?, effort?, threadId?, tools?, skills?, connection?`。混入文字引用前主软件先合并到 prompt；二进制引用不得静默丢弃。
- `options`：`outputDir, onProgress, signal, onToolCall`。
- 完成返回：`{state:'completed', outputs:[{path,type,mime,bytes?}], text?, remoteId, threadId?, turnId?, metadata}`。没有真实落盘结果不算成功。
- `onProgress` 中 ComfyUI 的 `progress:{value,max}` 是当前节点步数，不是整个任务百分比。主软件可显示节点进度，不应捏造总进度。
- `cancel(remote)` 中传回 `provider,remoteId,threadId?,turnId?,connection:task.snapshot.connection`，防止切换当前服务器后取消错任务。
- Codex `threadId` 仅用于本应用已有成员线程；主软件必须在调用前验证线程归属与画布权限。每个独立功能默认新线程，普通Agent对话可恢复自有线程。

ComfyUI 在提交前保存唯一 `client:UUID` 标识；如果POST响应丢失，可按同一个 client_id 查询队列与最多1000条近期history，不自动重交。已有 prompt_id 则按原ID恢复。远端完成但未保存返回 `completed-remote`。下载失败、断线、超时与取消未确认不能报告完成。

取消先核对精确排队/运行ID，不影响别人的任务。运行中取消只在明确配置 `targetedInterrupt:true` 时发送按ID中断；本机 `server.py` 已检查支持该参数。未知旧版实例默认拒绝发送全局中断。

排队取消在删除后同时回查等待队列、运行队列和执行历史。任务刚好转为运行或已经完成时，不会误报“已取消”。Comfy来源实例按冻结非密钥配置的稳定散列复用；修改当前设置不会改变旧任务的实例或丢失进程归属。状态列出 `ownedInstances`，停止仅针对本次软件实际启动的进程；复用已有8188服务保持非自有，不会关闭本次测试先前启动的服务。

首次配置可沿用上述安装目录，Python为该目录下 `.venv\Scripts\python.exe`，附加参数为 `--extra-model-paths-config` 和 `C:\Users\O.oInkMore\AppData\Roaming\Comfy Desktop\instance-model-paths\inst-1787467970326.yaml`。三个路径在2026-09-07再次检查均存在；不需更新或安装依赖。

## 原生编辑器

`createNativeEditor({BrowserWindow,Menu?,parent?,url,bundle?,onSave?,confirmReplace?})` 返回 `open, convert(gui,{replace?}), read, markSynced, close, dispose, isOpen`。

- 独立非持久 partition，不使用、重载或覆盖用户已有浏览器标签。
- `convert()` 真正载入原生图并调用 `app.graphToPrompt()`；`read()` 同步当前可见编辑器内容。返回 `{gui,api,selectedNodeIds}`。
- 检测到未同步编辑后拒绝覆盖，除非显式确认。普通关闭仅隐藏并保留草稿；应用整体退出才 dispose。
- 对一般第三方节点不按 widget 数组猜转换；本机12套固定配方虽有初始GUI作者工具，交付版本全部经过原生转换验证。

## 权限加固与待核对

已采用当前原生协议的 `environments:[]` 禁用模型文件环境，同时禁用 shell、浏览器、电脑操作、插件、记忆、自动Skill目录说明等子进程功能；不以一句开发者提示代替权限。MCP空表会深合并，故每个线程显式禁用所有已发现 MCP 并回查。Skill 默认禁用，仅显式选中项允许载入。工具调度所需的受限 code-mode host 保留，否则动态画布工具也无法工作；它不是 node_repl。

加固后的三项真实复测均成功：动态工具正确收到参数（`policy-result.json`）；无选中Skill时原生列表返回 EMPTY，显式选中本项目测试方法后准确回复专属标记（`policy-skills-result.json`）；无文件环境的Image2参考图仍返回1.59MB真实PNG（`image2-fa443121-7a0f-4e85-b74f-e6d5da2152c8.png`）。原生 `input.type=skill` 的本机路径在禁用环境后不自动加载，因此显式Skill采用提交时只读选中正文并冻结后传入；停用项不读、不发。其他本地文件和Shell权限不因方法文本恢复。

私人文字/Agent回合还通过真实 `features.image_generation=false` 禁止直接图像生成，只能用经过画布权限检查的显式动态工具提交独立任务；Image2专用回合保留该能力。最新真实动态工具回合 `01a07925-2f9f-75b1-a2b2-28c775a7f7c9` 成功，工具列表不再含 image_gen。私人会话控制器 `ChatSession` 只允许一轮活跃对话，冻结连接，仅停止这轮新收到的 thread/turn；停止不会取消动态工具另行提交的图片任务。状态未知时先保留原标识并核对，不自动重交。

风格步骤也已真实调用本地Qwen3完成中文改写，第二次输入相同命中本机缓存；代表帧拉片通过本地Qwen3-VL输出可解析镜头记录，原始时间来自FFmpeg，声音强制注明未分析，运镜注明代表帧推测待核对。证据 `testing-output/providers/creative/result.json`。缓存键包含完整原始/当前提示、参考文件内容哈希及端口角色、风格正文、选定模型/连接与参数；仅复用成功步骤，失败步单独重试，状态未知先按原任务核对。

风格卡已有Skill正文优先使用卡片独立副本，库更新不会替换它，库删除不破坏它。若同ID库条目仍存在且被明确停用，则新执行暂时受阻但卡片副本保留；排队前已冻结的任务不受之后库状态变化影响。这一“停用仍存在的库条目时阻止新加载”边界需与最终产品说明保持一致。

## 分批分析与卡片工具复核

拉片分析在 `dataDir/analysis-cache` 保存稳定检查点：素材内容与分析模型/参数/画布决定身份；取帧清单、每批真实远端标识、状态和成功镜头逐次原子保存。`runAnalysis(...,{recovery:true})` 对未知批次只查询原任务，不重复提交；已成功批次复用，失败或已取消批次仅 `retryFailed:true` 或用户重新提交相同分析时重做。确认取消保留已完成镜头，并给未完成范围添加缺失标记，返回 `partial:true`，不冒充整段成功。恢复查询暂时不可用仍保留未知状态，不能转成可重复提交的失败。

当前版本再次真实执行本地Qwen3-VL分析成功：Comfy任务 `d146c79c-4b51-40e0-a6f6-0a8bd071cbdc`，检查点 `testing-output/providers/creative/analysis-cache/62cce7c3372a39c609d17bf6cb1cfe8ff331b99d27bac87b539945c6645cbca2.json`。其中的运镜与音轨不确定性说明和真实镜头文字已回读核对。重启/断线/取消竞态另由模拟协议回归验证，不把模拟测试称为真实服务故障演练。

卡片工具资源按资源ID检查启停与来源真实媒体类型，固定所选工作流三份副本及参数；旧中文工具名不能绕过已停用内置资源。本地人像质感、多角度、打光、九宫格、标记使用图生图而非纯文生图，明确标注通用图生图能力限制。Image2工具只在改选Comfy时加载其本地替代工作流。视频重拍如有当前画布已登记的标注图，则以标注图替换单张参考，不再次取未标注帧覆盖它；原视频和原图保持不变。
