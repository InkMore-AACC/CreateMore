# 本地专用工作流实施记录

## 安装边界

沿用 Comfy Desktop 当前 ComfyUI 实例与共享 models 目录，不另装 ComfyUI。用户授权新增模型、节点和依赖共 100 GB。固定下载清单的新增权重为 40,381,318,677 字节，下载清单与逐文件校验位于共享模型目录 `.createmore-provision/manifest.json`。已有 VoiceDesign 权重不重复下载。失败下载产生的中间文件也计入实际占用，最终成功校验后清理本轮中间文件。

语音节点安装在当前实例 `custom_nodes/createmore_qwen_tts`。节点自身的 `runtime` 使用当前 Python，并引用主环境的 Torch；仅在该节点的子进程环境安装 Qwen 官方 SDK 所需依赖。主环境已再次核对：Torch 2.12.1+cu130、Transformers 5.14.1、Accelerate 1.14.0、huggingface-hub 1.25.1 均未改变。

官方 Qwen SDK 0.1.1 的 Transformers 4.57.3、Accelerate 1.12.0 与 huggingface-hub 0.36.2 只存在于节点隔离环境，不用于 ComfyUI 主进程。未安装 SDK 的 Gradio 网页界面依赖，也不在这个隔离环境运行 Diffusers。已通过实际 GPU 推理，而非以 pip 导入作为最终依据。没有 FlashAttention，采用 PyTorch SDPA；SoX 命令行未安装，当前三条实际生成路径均不调用其命令行功能。

## 图片实现与实际验收

Qwen Image Edit 2511 fp8mixed、LightX2V 2511 四步 LoRA、fal 多机位 LoRA；不混用 2509 的重光照 LoRA。多机位公开环绕、俯仰和景别。九宫格实际九个采样分支，共享模型和输入编码，最终合成 3×3；不以“请画九宫格”冒充九路结果。

区域编辑分开传原图、标注图、黑白遮罩，输出合成回原始像素；区域外零差异需要在实际结果上检查。界面支持区域涂抹和矩形区域，箭头与编号只用于说明。人像质感和打光仍需实际效果检验，不能因为换了专用编辑模型就标记完成。

- `qwen-images-1788853110948`、`qwen-images-1788853288026`：实际生成并查看人像、打光和局部编辑。修复低分辨率潜变量与参考编码尺寸不一致造成的放大裁切；人像默认降噪改为 0.35，保持构图，但细小身份特征与皮肤质感仍可能改变。
- 局部编辑实测遮罩外最大像素误差为 0，遮罩内有真实变化；加入内侧羽化。大块背景遮罩仍可能出现区域内亮度变化，不承诺无缝或精准语义。
- `qwen-images-1788853391446`：人物多角度与九分支九宫格实际输出并查看，能看到不同机位、俯仰与景别；对称陶杯不能单独作为角度变化的效果证据。
- `tool-ui-1788853664007`：人像、多角度、打光、九宫格通过真实界面提交与结果回写，但检查图片发现九宫格嵌套问题；标注流程另有保存后无法返回的问题，均未忽略。
- `tool-ui-1788854057838`：修复标注保存后的未提交状态残留，真实矩形圈画、保存、生成、结果回写通过。
- `tool-ui-1788854161338`：修复本地每分支仍要求画整张九宫格的旧提示词，实际回写图片已查看，确认为 3×3 九张画面，不再嵌套成 81 格。格子按原图比例合成。
- `specialized-native-1788853586009`：七种不同原生图结构 GUI→API 与公开参数回读通过；修复 seed 控件序列与 CFGNorm 隐式默认值不一致。最终图结构再次复核另存最新 `specialized-native-*` 报告。

## 来源与选择理由

- [Qwen 官方语音项目](https://github.com/QwenLM/Qwen3-TTS)：三种模型能力界限、官方 SDK 与参考录音接口。优先复用已有 VoiceDesign，再补 Base 和 CustomVoice。
- [1038lab 社区节点](https://github.com/1038lab/ComfyUI-QwenTTS)：参考节点能力划分与释放模型设计；没有整包照搬其依赖或源码。
- [Qwen Transformers 5 兼容分发](https://pypi.org/project/qwen-tts-hf/)：核对后未采用；其依赖与当前主环境仍不完全吻合。选择官方 SDK 的节点内隔离，避免改动主环境。
- [fal 多角度 LoRA](https://huggingface.co/fal/Qwen-Image-Edit-2511-Multiple-Angles-LoRA)：依据其 8×4×3 机位参数和触发词，自行构建图。
- [LightX2V 2511 Lightning](https://huggingface.co/lightx2v/Qwen-Image-Edit-2511-Lightning)：使用对应 2511 版本，不套用其他基座的加速权重。
- 当前 ComfyTV 的 multiangle 与 multiview 原生 JSON 作为图结构补充参考；检查了实际采样分支，并自行构建 CreateMore GUI/API/映射。

## 发布注意

构建时不能让旧 catalog 覆盖新增语音和图片工作流。新增合并保留旧目录项，并追加新 ID。五个图片工具只有旧文件哈希与已记录原版相同才自动升级；用户改过的资源原样保留。v0.4.0 最终路径以 `dist/latest-build.json` 为准；源代码版本备份上传私有 GitHub，完整 Windows-app 留在版本备份的 local-only，不上传个人模型、凭据与私人工程。
