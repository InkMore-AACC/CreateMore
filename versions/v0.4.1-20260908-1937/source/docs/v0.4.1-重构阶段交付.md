# v0.4.1 重构阶段版

## 本版改动

- 修复 Comfy V3 动态输入检查；阻止把编码器等非结果节点映射成输出。具体错误显示节点和参数，不再只给笼统失败。
- 候选版本默认图片工作流恢复为 ZImage 图片流程；错误指向 H3 视频图的旧版本仍保留，没有删除用户的历史工作流。
- 单参考、双参考 Qwen 指令编辑作为独立流程提供，不把普通重绘冒充精确编辑。
- 编辑映射使用真实 ComfyUI 画布，可选择节点和参数，公开控件并预览；同步后保存到卡片独立版本。
- 按用户最新选择，本地工作流与编辑映射直接显示在选中卡片上，不藏进模型菜单。
- 人像、多角度、打光、九宫格、高清先创建连线草稿；用户点击生成后才执行，结果返回这张卡片。原素材保留。
- 参考缩略图编号、可读的浮动编辑器、工具功能标签、移动/抓手切换及快捷键完善。
- 项目和画布入口在左上角，资产管理在左下角，Agent 与资产侧栏默认收起。参数面板为顶部导航、底部工具栏留空间。
- 启动 ComfyUI 有即时状态与防重复点击；切换来源会刷新真正适用的参数。不会因为失败自动转到收费来源。

## 不作过度承诺的范围

- 还不是 LibTV 每个工具、每种状态和每个手势的完整复刻。已观察和未观察分开记在《重构-LibTV交互对照表》。参考站只生成过一张图片，消耗 18 积分，没有生成视频。
- 图片身份保真、复杂编辑和语音自然度/音色相似度/情绪强度仍需素材效果验收；没有“全部最优”的结论。Base 克隆没有独立情绪指令，跟随参考表达。
- 局域网第二台实体电脑、断网/休眠、未配置的外部付费 API、Windows 签名证书不由本机测试代替。
- 继续使用原有 ComfyUI 和共享模型，没有另装或降级。本轮无新增模型下载；此前用户授权下载约 40.38 GB，累计预算为 100 GB。
- 用户正在使用的工程和原素材未改。切换版本前请保存、退出旧版；旧目录保留可回退。

## 软件目录

完整 `Windows-app` 是可移动的软件目录，不要只搬 EXE。模型、ComfyUI、Codex 登录和个人 API 由每台电脑单独配置。版本备份的 `local-only/Windows-app` 仅存本机，GitHub 只同步源码及公开资源，不上传模型、私人工程或凭据。
