# CreateMore

Windows 本地创作画布。已批准的 V5 草图保留在 `prototype/`，可运行软件位于 `app/`，交付程序位于 `dist/`。两者不是同一个页面。

## 开始使用

1. 双击项目根目录的 **启动 CreateMore.cmd**，或打开交付文件夹中的 **CreateMore.exe**。不要单独移动 EXE，需保留旁边的 `resources/` 等文件。
2. 在项目页选择“打开项目”，打开 `examples/实机验收工程`。里面的两张本地图片、Codex 文字、Image2 图片和 H3 短片是实际生成结果，不会因打开工程再次生成。
3. 或者新建自己的项目，选择任意可写文件夹。双击画布空白处添加节点，选中卡片后填写提示词、选择来源及参数，再点击生成。
4. `Ctrl+S` 手动保存。自动保存默认每 5 分钟、最多 100 份，仅在有变化时留一份，可在设置中修改。

本机首次连接已配置为现有 ComfyUI 的原 Python 与共享模型路径，Codex 复用本机订阅登录。当前 8188 后台可复用；未运行时，正常生成会按已配置环境启动。不会安装节点、更新环境或自动改用付费平台。

详细说明见 [使用说明](docs/使用说明.md)。实际验证和待确认事项见 [实施与验收记录](docs/实施进度与待确认.md)、[生成接入记录](docs/生成接入验证记录.md)、[LAN 验证记录](docs/LAN验证记录.md)。

## 数据在哪里

- 工程与素材：在你选择的项目文件夹。工程入口是 `.createmore.json`，每张画布有自己的同名目录和 `canvas.json`。
- 本机身份、连接、队列、私人对话和日志：`%APPDATA%\CreateMore`。不自动放入项目包，也不修改 Codex 全局配置。
- 内置与个人资源、默认工具流程：软件交付文件夹的 `resources/`。升级前保留整个资源目录；不要用新版目录直接覆盖自己的资源。
- 删除卡片不删除素材。复制项目用于迁移请使用软件“打包”，不要只复制 `canvas.json`。

## 当前交付边界

这是本地可运行的 0.1.0 版本，非已签名的公开商用发行版。真实多电脑 LAN、外部付费 API 密钥对应的模型、安装签名及自动更新服务尚未完成环境验收。两人共享时一人突然离线不会冒险强制接管，可保留完整副本另存独立项目。3D 导演台按要求仅预留。

本地 H3 音频流程适合环境音，不将其当作准确配音/音色克隆；这些专用能力需要另选对应工作流。通用本地图生图不保证精确遮罩、身份锁定或九宫格数量，可选择 Image2 或替换专用流程。每项实际证据与限制已分别记录。

## 开发和自动化

```text
npm install
npm start
npm test
npm run check
npm run build
```

CLI 与 MCP 使用正在运行的软件服务，不另开一个画布实例：

```text
node app/cli.cjs canvas.get
node app/mcp.cjs
```

需要外部 Codex 操作时，手动把 MCP 配置到所需项目；本软件不会自动安装或注入全局插件。内置 Agent 已直接接通相同的画布能力，不需要这一步。
