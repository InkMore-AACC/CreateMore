## 2. 组合功能和非 ComfyUI 入口

| 入口 | 实际路径 | 完成边界 |
|---|---|---|
| 普通图片选择 Codex Image2 | 本机 Codex App Server 专用图像回合→内置 image_gen→本机结果文件 | 文生图、参考图与产品服务回传已有真实证据；见生成接入记录及 application-live 报告 |
| 人像质感、多角度、打光、九宫格、标记 | 默认 Image2；本地替代为 `image-zimage-edit`，各自使用不同处理指令 | 已连接真实生成来源，不是效果保证。通用图生图不保证精确蒙版、身份锁定、局部不变或严格九宫格数量 |
| 反推提示词 | 默认 Codex 看图；可选 ComfyUI Qwen3-VL，或已确认看图能力的 LLM/API | 无看图能力的文字连接须拒绝图片输入 |
| 扩写、整理、识别资产 | 默认独立 Codex 功能回合；可选 Qwen3、Ollama、OpenAI-compatible 文字连接 | 不混用私人 Agent 会话；文字结果保存为新卡片 |
| 剧本转分镜工具 | 文字模型调用→解析为独立可编辑分镜卡 | 新增服务集成测试通过；模型未返回有效表格时保留“格式待整理”的原文卡，不冒充空分镜成功。普通分镜卡亦可选择本地 ComfyUI 文本绑定 |
| 风格步骤 | 改写指令后交给最终生成节点；本地无图使用 Qwen3，有图使用 Qwen3-VL；Codex/其他 LLM 亦可 | 本地改写、缓存已实测。来源选择界面的补充与恢复修复见第 3 节 |
| 逐帧拉片 | FFmpeg 按实际时间取代表帧→Codex 多图批次，或 ComfyUI 单图分析→独立可编辑分镜卡 | 并非逐视频帧调用模型；当前是定时代表帧，不保证准确自动切镜；运镜标为静帧推测，音轨未分析 |
| 片段重拍 | 实际视频时间点→FFmpeg 截图／用户标注 PNG→图生视频工作流→独立新视频卡 | 保留原视频，不自动覆盖或回拼；标注时间与工作流配置的最终验收见第 3 节 |
| 音视频截取、变速、切分 | FFmpeg 独立文件输出 | 实际执行回归位于 `tests/media.test.cjs`；原文件不覆盖。切分单次最多 200 段 |
| 取帧、分析代表帧、抽音轨 | FFmpeg；取帧时间来自程序记录 | 分析单次最多 120 个代表帧；没有音轨时抽取报错 |
| 分镜截图与文字取用、Excel 导出 | 已登记素材＋本地数据处理；ExcelJS 嵌入截图 | 不调用生成模型，不自动生成媒体 |
| 私人 Agent、显式 Skill | 本机 Codex；显式画布工具经过同一权限与任务服务 | 聊天停止不取消另行提交的生图任务；本轮未重新调用聊天或 Image2 |

Ollama 当前仅提供文字／可选看图的适配通道，本机是否运行需连接页实时检查。OpenAI-compatible 当前仅提供文字输出，可显式配置看图，不是通用图像或视频 API。RunningHub 是明确配置工作流及映射的远程执行通道，不因状态列出多种媒体能力就表示某个模型、工作流或付费账户已验收。外部平台没有本轮真实付费测试。
