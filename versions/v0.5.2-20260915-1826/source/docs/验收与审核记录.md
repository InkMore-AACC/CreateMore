## 审核发现与修复

采用 `cold-review-gate` 的无会话历史、只读独立审查方法。审查员不能写代码或执行生成，主代理核验并修复；文件访问边界仅为提示级约束，不宣称取得操作系统隔离的完整“真冷审认证”。冻结候选与摘要保存在 `.test-output/cr-*`，主代理复核候选哈希及完整包摘要。

| 发现 | 处置 |
|---|---|
| 重连素材可能覆盖尚未手动保存的编辑 | 已先保存当前会话再执行重连；真实文件回归通过 |
| 删除待运行任务与后台开始执行之间存在取消竞态 | 重新核对 pending／running／history；已完成不会误报取消；针对性回归通过 |
| 拉片失败不能可靠复用已完成批次 | 逐批持久化与原回执核对，局部成功可查看，人工修改不被后续恢复覆盖；回归及实际本地分析验证 |
| 结果已本地关联后，恢复可能跳过失败的共享发布 | 同一结果恢复仍执行必要同步，不新增重复素材；回归通过 |
| 图片仍在远端排队或只是下载失败时，恢复可能重复生成 | 原回执、种子和成功图片始终保留；明确失败与未知分开；25 项新增故障恢复回归通过 |
| 同步文字已经返回，但输出目录保存失败会丢失原文 | 原文先持久写入队列或步骤缓存，再保存 TXT；实际磁盘错误与服务重启的 9 项回归通过，API／Ollama 模型调用始终只有一次 |
| 共享任务可能使用提交之后变更的同名素材 | 请求固定 SHA-256 与大小，两端保留独立输入副本并校验；版本改变明确拒绝生成，不静默替换参考素材 |
| 两位成员交错上传同一素材 ID 可覆盖先提交者 | 串行提交内再次核对当时所有权；后提交者被拒绝，先提交者文件、节点、版本保持不变；连同引用冻结新增 4 项回归，相关 36 项全绿 |

另外统一所有 ComfyUI 入口的同实例调度，包括风格和拉片子步骤；等待外部已有队列，不清空别人的任务。补齐取消后已有图片的保存，以及退出前最后输入的同步。
