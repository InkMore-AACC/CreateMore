# LibTV 画布第三轮观察与写入验证记录

## 1. 本轮范围

- 实页：用户在 Edge 打开的 LibTV 测试画布，开始时共 178 个节点、100 积分。
- 方法：在用户授权范围内创建、重命名、复制和编辑测试节点，并提交一次纯文本生成；未生成图片、音频或视频，未删除、移动用户原有节点。
- 目的：在第二轮只读观察基础上，补足节点创建、复制、输出端快捷创建、自动连线、脚本表格编辑、计费和文本结果回填等写入行为。

## 2. 已直接观察并复核

### 2.1 画布与选中联动

- 大型画布可同时包含图像、视频、音频、文本、分镜表和分组容器，左侧目录按组列出节点。
- 从左侧定位节点会自动缩放并把目标置入视野；目录选中行、画布节点、右侧 Agent 引用标签同步更新。
- 未选中的连线保持细灰色；选中节点后，与其直接相关的连线转为高亮青蓝色，其余连线不变。
- 输入／输出端口在选中或悬停时显示圆形加号，不需要常驻干扰画面。
- 点击画布空白处会清空节点选中态、收起参数区和局部菜单，并移除 Agent 的当前节点引用。

### 2.2 图像结果与生成参数

- 成功结果卡在未选中时主要呈现媒体内容；节点名称和分辨率位于卡片外上方。
- 选中后，媒体上方显示与内容类型相关的横向工具条；图像示例包含人像质感、全景、多角度、打光、九宫格、高清、元素编辑、下载和展开等入口。
- 多结果任务在媒体角落显示数量叠层标识。
- 生成参数不是全局抽屉，而是连接在结果卡下方：参考素材、标记／风格／聚焦、提示词、模型、比例／清晰度／张数、高级设置、智能引用和提交入口集中在同一上下文内。
- 处理结果卡仍可继续连接到下游节点；输出内容和再次生成参数同时保留。

### 2.3 文本、音频和失败态

- 文本结果可以直接呈现较长的富文本内容，并从单个输出端口连接多个下游节点；选中后可显示引用素材、原始输入和模型参数。
- 成功音频卡使用波形、播放按钮、进度和时长表达；选中工具条包含截取、变速、智能切分、自定义切分和下载。
- 失败节点不是空白占位：卡片内明确显示红色失败标识、可读原因和 TaskID；选中后仍保留可修改的参数区和重试入口。

### 2.4 分组与分镜表

- 分组是位于节点背后的半透明容器，不替代节点本身；选中分组后才出现整组执行、添加到工具箱、转分镜组、解组和批量下载。
- 分镜节点是可横向滚动的结构化表格，字段可覆盖镜号、时长、画面描述、角色、参考、景别、情绪、光影、音效、对白以及图像／视频提示词。
- 分镜表支持脚本视图与创意视图切换，并提供重新生成、生成分镜、下载和全屏展开。
- 分镜表下方仍可接引用、提示词和模型参数，与普通生成节点保持一致的“结果在上、参数在下”关系。

### 2.5 节点创建、复制与输出端快捷创建

- “添加节点”一级入口包含：文本、图片、视频、智能剪辑 Beta、导演台 NEW、逐帧拉片 SD 2.5、音频、脚本、素材库；资源入口另有“上传”和“从生成历史选择”。
- 已新建并重命名文本节点 `CM结构测试-文本`。空白文本节点提供“自己编写内容、文生视频、图片反推提示词、文字生音乐”，默认模型为 `GVLM 3.1`，界面标示消耗 6 积分。
- 已新建并重命名图片节点 `CM结构测试-图片`。空白图片节点提供图生图、图片高清、参考、标记、风格、聚焦；默认模型为 `General image Pro`，配置显示 `16:9 · 2K · 1张`、14 积分，联网搜索关闭、智能引用 AutoLink 开启。
- 复制图片节点后生成独立副本 `CM结构测试-图片 - 副本`，节点数增加 1，副本继承模型、规格、价格和开关状态，并成为当前选中节点与 Agent 引用。
- 点击图片副本右侧输出端的加号，真实弹出“引用该节点生成”，可选文本、图片、视频、智能剪辑 Beta、导演台 NEW、音频、脚本；“逐帧拉片 SD 2.5”在该上下文中禁用。
- 在输出端菜单选择“文本”后，系统新建下游文本节点，节点数从 181 增至 182，并出现从图片副本到新文本节点的真实连接边；下游文本输入自动预填“根据图片生成提示词”。这证明快捷创建与自动连线是一个原子操作。

### 2.6 生成、计费与新版脚本写入

- 在 `CM结构测试-文本` 提交一次纯文本请求，积分从 100 降至 94，节点回填标题、三条编号正文和下载入口。结果很快完成，未捕捉到稳定的排队中间态，因此只能确认“提交、扣费、结果回填”，不能据此描述完整队列状态机。
- “脚本”入口分为“脚本 NEW”和“脚本（旧版）Beta”。新版空白节点名为“脚本 V2”，提供“剧本生成分镜脚本、角色生成分镜脚本、自己编写分镜脚本”，生成模型为 `GVLM 3.1`、标示 6 积分。
- 选择“自己编写分镜脚本”不会提交模型，而是打开三阶段编辑器：确认镜头、准备资产、合成提示词；表格字段包括镜号、时长、画面描述、景别、光影氛围、对白·旁白、音效、运镜、最终提示词和操作。
- 已在新建脚本节点 `CM结构测试-分镜脚本` 的画面描述单元格写入并保存测试内容。保存后状态由“1 个镜头待核对”变为“1 个镜头已就绪”，完成度由 `0/3` 变为 `1/3`，证明单元格编辑和阶段状态联动有效。
- 本轮最终共 183 个节点，保留 94 积分；共新增 5 个测试节点（文本、图片、图片副本、自动连线文本、分镜脚本），没有生成视频。

## 3. 已落入 CreateMore 草图 V3

- 左侧增加“画布／素材／历史”切换和节点目录定位。
- 节点改为“外置名称与尺寸 + 内容卡 + 选中工具条 + 附着参数区”。
- 新增相关连线高亮、选中／悬停端口、Agent 引用同步、空白取消选中。
- 新增多结果图像、文本、音频、失败节点、分镜表和分组容器示例。
- 新增图像九宫格局部菜单、分镜视图菜单、任务队列和失败定位演示。
- 新增“添加节点”分类面板、输出端“引用该节点生成”菜单，以及新版脚本三阶段编辑器的结构提示。
- 分镜表中的核心内容单元格改为可直接编辑，用于表达已验证的就地编辑行为。

## 4. 尚未验证

- 真实验证过一次 LibTV 文本生成与扣费，但未观察到可复现的排队中间态，也未验证图片、音频或视频生成；尤其视频按用户要求明确未触发。
- 输出端快捷创建和自动连线已验证；手工拖拽节点、手工从端口拉线到既有节点、删除连线、多选与分组写入仍未验证。
- 新版脚本的单元格编辑和阶段状态已验证；资产准备、提示词合成、批量分镜、下载以及任何批量生视频行为未执行。
- CreateMore 当前仍是前端交互草图，未连接 Codex、ComfyUI 或外部生成服务。
