# v0.5.0 交互与卡片架构

## 本版完成

- 普通图片、视频、文字、声音卡片与对应生成卡片在数据和界面上分离。普通素材只显示素材与顶部工具栏；生成卡片才显示底部生成面板。
- 图片生成面板按确认结构排列：添加参考、标记、风格、聚焦、扩大，素材输入条、提示词、三种生成来源、画面规格和生成按钮。
- 本地 ComfyUI 不再在单张普通生成卡片里任意挑选工作流。图片、视频、声音、文本、脚本分别在全局设置中绑定，图片／视频再按无图、单图、多图自动路由；工具工作流不会混入普通生成列表。
- 素材输入条支持悬停预览、取消引用、拖动排序与 `@` 引用。
- 连线可以从端口附近起拖，并可放到兼容卡片范围内；新卡片出现在鼠标位置，不自动改变画布视角。
- 工具栏与生成面板保持卡片相对位置，允许超出当前视口，不自动翻边或挪动画布。
- 图片和视频卡片读取真实素材尺寸后按原始宽高比自适应；未生成图片按选定比例变化。
- 多张图片结果支持堆叠、展开和设为主图。
- 聚焦使用真实框选，在原图右侧创建新的生成图片卡片；本地流程执行裁切、4x-UltraSharp 放大和至少 1M 像素输出。

## 本轮验证

- 产品脚本语法检查通过。
- 355 项完整自动测试通过。
- 隔离 Electron 窗口 38 项端到端交互通过，控制台错误为 0。
- 当前本机 ComfyUI 的 1662 个节点定义完成聚焦流程结构校验。
- AAA 素材完成一次真实聚焦工作流输出：1024 × 1024 PNG、1,079,651 字节。

## 仍需持续实测

- 不把某一张图片的成功输出当作所有图片、视频、声音、文字工具均已完成真实模型验收。
- 外部 API、局域网第二台真实电脑、不同模型组合与长视频仍需各自独立验收。
- LibTV 后续发生变化时，需要重新实操对照，而不是根据旧截图推断。
