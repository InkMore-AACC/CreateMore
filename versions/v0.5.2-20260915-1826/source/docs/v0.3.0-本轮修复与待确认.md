# v0.3.0 本轮修复与待确认

日期：2026-09-08。本文记录本轮新增证据；早期文档中的验收数量不代表本轮重新运行。没有把所有平台、所有工具效果或所有 LibTV 手势标为完成。

## 已修复

- 映射入口打开实际 ComfyUI 工作流画布。点击节点后，旁侧显示真实节点参数，可设卡片参数、提示词、素材输入或固定值；支持名称、说明、默认值、范围、素材顺序及数组输入。原生前端导出执行数据，不猜第三方节点转换。
- 在实际输出节点上公开结果字段、媒体类型、主预览及必需性。字段必须来自真实运行历史；不再根据 SaveVideo 等类名猜成 videos（本机 SaveVideo 实际返回 images）。导入工作流须核对输出后保存。
- Ctrl+S 将原生窗口草稿同步回映射页，随后保存工作流版本。不同工作流的窗口会话标识隔离，旧窗口不能覆盖另一份映射。关闭窗口保留草稿，不结束 ComfyUI。
- 普通本地卡片可直接选择文生图／图生图、文生视频／图生视频等工作流，并显示所需素材。参数读取卡片实际绑定，而不是错误地始终读取全局默认。
- 参数／素材预检查提前到调度器启动后台之前；错误素材不再先启动服务。布尔参数保留布尔类型。
- 工具结果卡片保留原任务标识和正确来源，不再把本地结果标成 Image2。
- 拖线创建尊重鼠标落点并避开已有卡片；Esc 可取消拖线。竖版参数面板限制在工作区内；Ctrl+Enter 提交选中卡片，Ctrl+0 适应画布。
- 连接页显示后台运行数、排队数和显存。可手动请求空闲模型释放，也可选择完成后空闲释放；默认仍保留模型以加快下一次生成。有任务或远程地址时拒绝释放。
- 停止本软件启动的空闲 Windows 后台时，处理自有 Python 进程树，不按 python.exe 名称杀其他软件。停止与卸载模型是不同操作。
- 恢复副本保存到各目录的“备份”文件夹；工程重命名后丢失也能查找对应备份。备份不是双击入口。
- 工程关联补充 Windows“打开方式 → CreateMore.exe”的专用工程图标注册，不修改受保护的 UserChoice。

## 日后“失败但显存仍满”如何定位

先看连接页的后台运行／排队数，别只看卡片红色失败状态。队列空闲但显存高，先点“空闲时释放模型显存”，稍后重新检测；这是模型缓存，不一定有任务仍在生成。队列不为空则到原任务详情核对远端编号与 ComfyUI 队列。

只关闭本次软件明确启动且空闲的后台。外部 ComfyUI 在其启动器结束。Windows 任务管理器“详细信息”可开启 PID、命令行列，核对 `main.py` 路径与 `--port`。不要结束全部 python.exe，也不要只结束 venv 父进程而留下执行子进程。
