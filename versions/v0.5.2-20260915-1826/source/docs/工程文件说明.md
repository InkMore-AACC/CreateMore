# CreateMore 新工程文件

Windows-app 是完整软件主目录。双击其中的 CreateMore.exe 启动。

新建项目时请选择空文件夹。项目根目录中的“项目.createmore”是项目工程文件；各画布目录中的“画布.createmore”是该画布的工程文件。它们直接保存工程数据，不是快捷方式。可重命名文件，但请保留 .createmore 后缀，且每个目录只留一份工程文件。

在软件“设置 → 关联／修复工程文件图标”中完成关联后，可以从资源管理器双击打开。Windows 若询问默认程序，请选择 CreateMore。工程图标是带折角的 O.o 文件图标，与软件启动图标不同。

软件已运行时，打开另一工程前会保存当前画布。保存失败、有未提交的面板编辑或正在共享而不允许切换时，保留当前内容并说明原因。

搬移工程请搬整个项目文件夹，不要单独移动工程文件；图片、视频等仍在配套目录。外部引用素材不会随普通复制自动搬移，发送工程请使用“打包整个项目”。移动 Windows-app 后，在新位置运行软件并修复文件关联。

本版本仅支持新工程格式（内部版本 2）。不读取、不转换旧 JSON 工程，不会删除旧项目。自动保存、恢复备份、素材索引等为内部文件，不是双击入口。

examples/新工程示例 是新格式空白示例，不是旧版本的实机生成验收项目。

恢复副本“文件名.previous”从本版起放在各目录的“备份”文件夹，不是需要打开的工程。Windows 若以前通过“打开方式”选过 EXE，升级后再执行一次“关联／修复工程文件图标”。
