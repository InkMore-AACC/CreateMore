## 2026-09-09 卡片与交互定稿

- 卡片种类：普通图片、生成图片、普通视频、生成视频、普通文本、生成文本、生成脚本、普通声音、生成声音、自定义、风格。没有角色卡片；角色属于资源／预设体系。
- 上传文件、从资产栏拖入或重新使用生成结果时都创建普通素材卡片。普通卡片只有与媒体类型一致的顶部工具栏，不出现下方生成框。由“新建图片／视频／文本／声音”等入口创建生成卡片，才出现生成框；两者顶部工具栏相同。
- 生成图片框固定在卡片下方，顶部依次为添加参考、标记、风格、聚焦和最右扩大；有输入时才显示可预览、排序、移除的素材栏；提示词支持 `@` 指向已连接素材；底部为来源、比例／分辨率／数量和生成。
- 图片比例含 1:1、9:16、16:9、3:4、4:3、3:2、2:3、21:9 及自定义宽高；分辨率 1K／2K／3K／4K；数量 1／2／4。多结果先堆叠，展开后每张可设为主图。
- 添加参考进入画布点选模式，只允许图片类卡片亮起并创建输入连线；普通文本只通过连线成为输入。聚焦框选原图区域后，在原卡片右侧创建生成图片卡片，原卡片成为其输入。
- 图片和视频卡片按实际媒体宽高比自适应，不裁掉画面。无结果的生成卡片按所选目标比例变化。
- 从输出点附近即可拉线，拖到兼容卡片范围内即可连接，无需精确命中输入点。新建卡片位于鼠标位置，不自动整理、避让或移动视口。
- 顶部工具栏及下方生成框始终固定相对卡片的位置，所有按钮完整展开；即使超出视口也不换边、不压缩进“更多”，由用户自行平移或缩放画布。
