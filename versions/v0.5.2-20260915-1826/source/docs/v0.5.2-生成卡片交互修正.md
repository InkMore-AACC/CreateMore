# v0.5.2 生成卡片交互修正

## 已确认交互

- 图钉点击图片物体后，由配置的多模态来源识别名称和归一化外接范围。图片上显示图钉、名称和虚线框；提示词中显示可删除的行内图钉芯片。
- 图钉和名称只属于界面表达。工程提示词保存不可见对象 ID，提交生成时才展开为对象名称、当前参考图坐标范围和“不得绘制图钉／虚线框／标签／坐标／说明文字”的约束，避免把交互控件生成进图片。
- 图片上的图钉和提示词中的对象芯片使用同一对象 ID；任一处点击叉号都同步删除两处记录。
- 比例预设与自定义宽高为同一个单选组。自定义被选择时单独高亮，预设不再保持选中；反向选择亦然。点击规格窗口外空白处自动应用，不保留“确定”按钮。
- 聚焦有效框选在松开鼠标后自动创建右侧生成图片卡片，不保留确认按钮。输出比例固定为框选比例，分辨率和实际像素按该比例换算，最低一百万像素。
- 卡片下方的生成编辑框锚定卡片，但通过反向缩放保持固定屏幕尺寸与间距；画布缩放和平移不会把编辑框改成难以阅读的大小，也不会为它自动移动画布。
- 提示词扩大按钮打开独立顶层窗口。窗口比卡片编辑框大，可拖动边缘调整尺寸；点击窗口外遮罩或按 Esc 关闭，不修改画布视野。

## 验证边界

- 产品脚本语法检查和 362 项自动化回归全部通过。对象引用回归验证：工程提示词只保存不可见对象 ID；生成快照展开出名称、归一化范围和禁止绘制界面标记的约束。
- 隔离 Edge 实际交互通过：自定义比例 `588:452` 唯一选中并在点空白后保存；生成框在 50%／100% 缩放下宽度均为 `620px`、屏幕间距均为 `14px`；聚焦没有确认按钮，松手后返回 `540:400` 框选比例、`2048 × 1520` 输出尺寸并自动关闭。视觉截图在 `.test-output/v052-visual/`。
- 当前自动化宿主无法完成 Electron EXE 窗口验收：GPU 子进程因系统 DLL／图形运行库问题退出，旧 v0.5.1 包同样复现。此项记录为环境阻塞，不写成 v0.5.2 正式 EXE 通过。
- 结构检查、DOM／Edge 交互和正式 EXE／真实生成须分别记录；以上通过不等于真实多模态识别质量或最终生成视觉质量已经验收。
- 本版只修改上述页面和交互，不改用户本机 ComfyUI、模型、工作流映射或连接配置。
