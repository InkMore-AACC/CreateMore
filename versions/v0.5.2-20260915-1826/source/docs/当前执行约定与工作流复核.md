## 本轮发现与代码修正

1. 五个专用图片工具实际共用 Z-Image 图生图。现在本地提交前明确提示能力未验收；只有主动选择“尝试通用重绘（实验）”才继续该替代流程。自定义专用绑定和 Image2 不因此被禁用，也不被宣称已验收。
2. 文字工具中，补充要求曾通过 `parameters.prompt || sourceText` 替掉原文。真实“剧本转分镜”因此生成舞台剧情，而输入是摄影师摆放陶杯、小花。现在总是保留原始文字，再附加处理要求；复验已生成符合原文的两条分镜。
3. 分镜 schema 原先只有 size、camera 等英文名称，模型把景别写成像素尺寸。补充中文字段含义，区分景别与运镜，并要求不虚构对白。
4. 新增独立界面验收：从实际工具栏或“更多”菜单点击，填写表单并用鼠标提交，经正式 preload、IPC、任务队列和本地服务回到结果卡片。测试工具自身也修复了误点隐藏旧菜单元素的问题；因此早期“未提交”不能全部归咎于产品。
